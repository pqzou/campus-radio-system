# campus-radio-system

一个给校园广播室用的在不改变校园流程行政流程的点歌网页。

最初是为了解决我所在的学校广播室收集播放歌曲麻烦的问题：班长将歌发在群里，格式不统一，找视频链接失效、版本问题、排队、记录播放等。

## 它能做什么

- 班级按班级名提交歌曲，填写歌名、作者、上传人和备注即可，不需要自己找视频链接
- 系统会在已登记的 B 站 UP 主视频里自动匹配播放链接、当匹配不到时，广播室审核时可以手动补BV号或者链接
- 广播室在播放页逐首试听、通过或拒绝。拒绝可以写原因，审核结束后能一键复制未通过名单发布到群内
- 播放页按班级和顺序排队，支持手动切歌、自动连播、记录播放位置、标记完成和取消完成
- 右侧播放列表可以按班级筛选，方便找到某个班还没播的歌
- 后台可以开关上传通道、设置单班曲目上限、维护已验证的 B 站 UP 主、查看上传审核记录
- 管理员账号在第一次使用时自行设置，之后可以修改用户名和密码

## 运行环境

- PHP 7.4 及以上（推荐 8.0+）
- MySQL 5.7 / 8.0
- 服务器需要能访问网站 bilibili.com，否则自动匹配和视频播放会受影响

## 部署

1. 把项目放到网站目录。
2. 修改 "config.php" ，填入数据库地址、库名、用户名和密码
3. 数据库账号有建库权限时，首次访问会自动创建库表；没有权限的话，需要先手动导入 "install.sql"
4. 浏览器打开打开网页后点击 "系统设置" 。第一次使用会要求设置管理员用户名和密码
5. 在后台“已验证 B 站博主”里添加常用的 UP 主 UID，自动匹配才会生效。如果 "已验证 B 站博主" 为空，则需要在审核时手动填入视频链接

## 使用教程

### 班级提交

打开网站进入主页，输入班级名称，填写上传人姓名、学号和歌曲信息后提交。提交后等待广播室审核

### 广播室审核与播放

打开 "大屏播放与审核" ，如果系统内存在待审核歌曲时则会弹出审核窗口。在审核后后可以选择“通过”或“拒绝” ，通过的歌曲会进入右侧播放顺序，按班级和顺序播放

播放过程中可以手动切换、重播或标记完成。标记完成的歌曲会进入“已播放完毕”，需要重新播放时可以点“取消完成”

### 后台管理

 "系统设置" 可以启用或关闭上传通道、调整单班歌曲上传上限、已验证 B 站博主、查看所有上传和审核记录，也可以修改管理员账号密码

## 配置说明

### config.php

用于存储数据库连接信息

### site-config.php

可在 "site-config.php" 文件内更改页面顶部标题、副标题、页脚文字和上传须知内容

## 其他说明

- B 站外链播放器不提供播放、暂停和进度接口，所以播放页的自动连播是按歌曲时长估算的。在内嵌播放器里暂停时，页面无法感知；如果需要暂停后不自动切歌，可以先关掉 "自动连播" ，当然我们也在继续寻找解决方案。

## 目录结构

```
api/         审核、进度和完成状态接口
assets/      样式、前端脚本和校徽图片
includes/    公共页头页脚
lib/         数据库初始化、B 站匹配等公共函数
upload.php   班级提交页
player.php   大屏播放与审核页
settings.php 后台设置页
install.sql  可选的数据库初始化脚本
```
